## 🔑 How to Get Started (Very Simple)

1. **Login** to your [SmileOne Account](https://www.smile.one/)
2. **Copy** the `PHPSEED` cookie value
3. Use it in the API URL as `PHPSEED=your_php_seed`
4. **Done!** No complicated headers or authentication needed.
